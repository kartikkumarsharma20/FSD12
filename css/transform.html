CSS Transform

translate()

Moves in X and Y direction.

translateX()

Moves horizontally.

translateY()

Moves vertically.

scale()

Changes width and height.

scaleX()

Changes width.

scaleY()

Changes height.

rotate()

Rotates the element.

rotateX()

Rotates around X-axis.

rotateY()

Rotates around Y-axis.

Combined

Translate + Scale + Rotate.
